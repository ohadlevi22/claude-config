# nano-banana-prompt-builder

Claude Code skill that builds professional image-generation prompts for Nano Banana
(Gemini 2.5 Flash Image) via interactive Q&A using photography and cinematography terms.
No API needed; outputs copy-paste ready prompts.

## Install

```bash
cp -r nano-banana-prompt-builder ~/.claude/skills/
```

Then invoke with `/nano-banana-prompt-builder` in Claude Code. See `INSTALL.md` and
`SKILL.md` for details; `library/` holds the style, ingredient, and example catalog.
